# Сгенерированные TypeScript-контракты

Каталог предназначен только для воспроизводимо сгенерированных TypeScript-клиентов, service descriptors и типов. Ручное редактирование сгенерированных файлов запрещено; `package.json` и служебная документация сопровождаются вручную. Код обновляется командой `task api:generate`, а его актуальность проверяется `task api:generate-check`.
