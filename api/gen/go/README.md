# Сгенерированные Go-контракты

Каталог предназначен только для воспроизводимо сгенерированного Go-кода. Ручное редактирование файлов, кроме `go.mod`, `go.sum` и служебной документации, запрещено. Код обновляется командой `task api:generate`, а его актуальность проверяется `task api:generate-check`.
