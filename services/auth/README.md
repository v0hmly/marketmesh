# Auth

Сервис владеет учётными данными, внешними сессиями, факторами аутентификации, отзывом и выпуском короткоживущих внутренних утверждений. Внешний пользовательский токен не покидает границу Auth.

Граница ответственности определена в [ADR-0006](../../docs/adr/0006-auth-and-user-bounded-contexts.md).
