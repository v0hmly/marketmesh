# Сервисы

Каждый каталог первого уровня содержит независимо развёртываемый Go-модуль. Сервис не импортирует внутренние пакеты соседнего сервиса и взаимодействует с ним только через protobuf-контракт либо доменное событие.

Внутренняя структура сервиса следует [ADR-0011](../docs/adr/0011-go-service-hexagonal-architecture.md). Каталоги `cmd`, `internal/domain`, `internal/application` и `internal/adapter` создаются вместе с реальным кодом, а не как пустой шаблон.
