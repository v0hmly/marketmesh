# Сгенерированные TypeScript-контракты

Каталог предназначен только для воспроизводимо сгенерированных TypeScript-клиентов, service descriptors и типов. Ручное редактирование сгенерированных файлов запрещено; `package.json` и служебная документация сопровождаются вручную. Код обновляется командой `task api:generate`, а его актуальность проверяется `task api:generate-check`.

Пакет экспортирует только пути публичных Auth/User-контрактов и стандартный
`google/rpc/error_details_pb`. Последний генерируется pinned protoc/protoc-gen-es
из той же ревизии googleapis в `api/easyp.lock` (Apache-2.0), чтобы браузер разбирал
структурированную ошибку подготовки профиля. Внутренние transport/assertion пути
не входят в package exports; frontend дополнительно ограничивает доступные
дескрипторы публичным фасадом и lint-правилами.
