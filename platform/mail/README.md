# Mail

Рендер транзакционных писем MarketMesh из встроенных шаблонов. Пакет только
собирает письмо (`From`, тема, прехедер, HTML и plaintext части); отправка по
SMTP остаётся на стороне вызывающего сервиса (в локальном контуре — Mailpit,
см. `infra/mailpit`).

Шаблоны повторяют прототипы `docs/design/prototypes/Email*.dc.html`:

- табличная вёрстка с инлайн-стилями и захардкоженными hex из
  `docs/design/design-system/tokens.json` — CSS-переменные почтовые клиенты не
  поддерживают;
- Georgia в заголовках, системный sans (Inter → Segoe UI → Arial) в тексте,
  mono в кодах и IP-адресах;
- тёмная тема через `color-scheme` и `@media (prefers-color-scheme: dark)`;
- одно письмо — одно действие; в письмах безопасности основная кнопка —
  защитное действие;
- код входа уходит письмом, резервные коды — нет (письмо ведёт за ними в
  аккаунт).

## Использование

```go
r, err := mail.NewRenderer(mail.Brand{
    Domain:              "marketmesh.ru",
    SupportEmail:        "help@marketmesh.ru",
    SellersSupportEmail: "sellers@marketmesh.ru",
    ITSupportEmail:      "it@marketmesh.ru",
})
if err != nil { /* конфигурация неполная */ }

msg, err := r.Render(mail.TemplateCode, mail.CodeData{
    RecipientEmail:   "anna@example.ru",
    Code:             "482913",
    CodeTTL:          "10 минут",
    PasswordResetURL: "https://marketmesh.ru/reset?t=…",
})
```

`Render` проверяет тип данных (должен совпадать со структурой шаблона) и
вызывает её валидацию — пустые обязательные поля отклоняются до рендера.
Значения бренда доступны в шаблонах функциями `domain`, `supportEmail`,
`sellersSupportEmail`, `itSupportEmail`; поля письма — через `.Data.*`
(в HTML/text) и напрямую (в теме и прехедере).

Сроки и даты приходят уже отформатированными по-русски («10 минут»,
«21 сентября 2026, 14:03, UTC+3») — пакет не форматирует время и не занимается
плюрализацией. HTML-экранирование выполняет `html/template`.

## Шаблоны и контракты данных

| Шаблон | Событие | Данные | Тема |
| --- | --- | --- | --- |
| `verify` | регистрация, подтверждение почты | `VerifyData`: почта, ссылка, срок ссылки | Подтвердите почту в MarketMesh |
| `code` | код подтверждения входа | `CodeData`: почта, 6 цифр, срок кода, ссылка на смену пароля | Код для входа в MarketMesh |
| `new_login` | вход с нового устройства | `NewLoginData`: почта, время, устройство, браузер, IP, локация, ссылка на смену пароля | Вход в аккаунт с нового устройства |
| `password_reset` | запрошен сброс пароля | `PasswordResetData`: почта, одноразовая ссылка, срок | Сброс пароля в MarketMesh |
| `password_changed` | пароль изменён | `PasswordChangedData`: почта, время, устройство/браузер, IP, ссылка восстановления | Пароль от аккаунта изменён |
| `email_change_alert` | запрошена смена почты (старый адрес) | `EmailChangeAlertData`: старая/новая почта, время, IP, ссылка и срок отмены | Запрошена смена адреса почты |
| `email_change_confirm` | подтверждение нового адреса | `EmailChangeConfirmData`: старая/новая почта, ссылка, срок | Подтвердите новый адрес почты |
| `account_locked` | блокировка входа после подбора пароля | `AccountLockedData`: почта, срок блокировки, время, число попыток, IP, локация, ссылка на смену пароля | Вход в аккаунт временно заблокирован |
| `sessions_closed` | закрыты все сессии | `SessionsClosedData`: почта, время, ссылка входа | Мы закрыли сессии на всех устройствах |
| `two_factor_on` | подтверждение входа включено | `TwoFactorOnData`: почта, ссылка на резервные коды | Подтверждение входа включено |
| `two_factor_off` | подтверждение входа отключено | `TwoFactorOffData`: почта, время, устройство/браузер, IP, ссылка включения | Подтверждение входа отключено |
| `backup_codes` | резервные коды обновлены | `BackupCodesData`: почта, число кодов, ссылка на коды | Резервные коды обновлены |
| `seller_decision` | решение по заявке продавца | `SellerDecisionData`: магазин, `Approved`, ссылка на портал; при одобрении — `GuideURL`, при отказе — `RejectReason` и `FixInstructions` | Магазин подключён / Заявка отклонена |
| `staff_invite` | приглашение сотрудника | `StaffInviteData`: кто пригласил, роль, ссылка, срок приглашения | Доступ к внутреннему порталу MarketMesh |
| `account_deleted` | запрошено удаление аккаунта | `AccountDeletedData`: почта, дата удаления, ссылка отмены | Аккаунт будет удалён {{ дата }} |

Файлы шаблонов: `templates/<имя>.html` и `templates/<имя>.txt`, общий каркас —
`templates/base.html`. Новые письма добавляются парой файлов, записью в `specs`
и строкой в этой таблице; тесты проверяют рендер всех шаблонов, отсутствие
неподставленных плейсхолдеров и экранирование.
