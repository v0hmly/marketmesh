# Git hooks

Репозиторные Git hooks подключаются один раз после клонирования:

```bash
task hooks:install
```

Команда настраивает локальный `core.hooksPath=.githooks`, не изменяя содержимое `.git/hooks`. Если `core.hooksPath` уже указывает на другой каталог, установка завершается ошибкой, чтобы не отключить существующие hooks незаметно.

`pre-commit` запускает `task verify` из корня текущего worktree и блокирует коммит при любой неуспешной проверке. Обход через `git commit --no-verify` допустим только как явно согласованное исключение из процесса.
