# Дизайн MarketMesh

Здесь лежит визуальный язык storefront и прототипы экранов, собранные на нём.

## Что где

| Папка | Что внутри |
| --- | --- |
| `design-system/` | Сама система: описание, токены, документация компонентов, готовый `bundle.css` |
| `prototypes/` | Прототипы экранов: вход и регистрация, страницы ссылок из писем, витрина, кабинеты покупателя и продавца, знак, письма авторизации |

## design-system

Система извлечена из `frontend/apps/storefront/src/style.css` и его Vue-представлений кабинета,
поэтому источником истины для уже написанного кода остаётся сам `style.css`. Для нового кода
источник истины — `tokens.json`: любые новые значения сначала появляются там.

| Файл | Назначение |
| --- | --- |
| `README.md` | Основания системы: цвет, типографика, сетка, форма, фокус, состояния, иконографика, голос |
| `tokens.json` | Все токены с парами значений для светлой и тёмной темы и заметками об использовании |
| `tokens.css` | Сгенерированный из `tokens.json` слой CSS-переменных — **править вручную нельзя** |
| `generate-tokens-css.mjs` | Генератор `tokens.css`: `node frontend/tools/generate-tokens-css.mjs` |
| `components/bundle.css` | Стили компонентов на токенах, без единого литерального значения |
| `components/*.md` | По файлу на компонент: структура разметки, состояния, правила и известные отклонения |
| `design-system.json` | Метаданные системы: имя, пространство имён, версия |

Тёмная тема раскладывается в три места, как требует `frontend/apps/storefront/AGENTS.md`:
`:root`, `:root[data-theme='dark']` и `@media (prefers-color-scheme: dark)`. Генератор делает
это сам, так что расхождения между темами возникнуть не может.

### Знак `.brand-mark`

Класс починен в `components/bundle.css` и в `frontend/apps/storefront/src/style.css`
(MM-82): коробка 35×35 в `border-box`, без `letter-spacing`, `padding-right` и
`overflow`; буква центрируется флексом и `translateY(-0.06em)`. Бывший слой-поправка
`.brand > .brand-mark` из `prototypes/tokens-vars.css` удалён — новые поправки поверх
знака не вводятся.

## prototypes

Прототипы собраны на канве и сохранены здесь как исходники. Это макеты, а не продакшен-код:
разметка на флексах с инлайновыми стилями и CSS-переменными. Подробности — в
[prototypes/README.md](prototypes/README.md).

`design-system/tokens.css` — локальный артефакт, отсутствующий в Git. Перед
использованием CSS выполните `task design:generate` (или общий `task generate`).
Источник изменений — `tokens.json`; генератор и ручные стили компонентов остаются
в репозитории.
