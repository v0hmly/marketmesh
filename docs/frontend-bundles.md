# Размеры и загрузка frontend в MM-87

Замер 24.09.2026: Node.js 26.0.0 на macOS arm64, pnpm 11.19.0, Vite 8.3.0,
Vue 3.5.42; зависимости из frozen lockfile, production target es2022, без sourcemaps.
Включены все восемь флагов Account/Seller, аналитика выключена. Контейнерная
сборка проверена на закреплённом Node.js 24.19.0. Сравнивать результаты нужно
при одинаковых флагах и версиях, а не только по имени entry-файла.

## Методика и команды

```sh
task frontend:bundles
task frontend:bundles:browser
```

Первая команда строит оба приложения со всеми возможностями и пишет JSON в
игнорируемую `.cache/frontend-bundles/`. `frontend/tools/bundles.mjs` читает manifest
Vite и считает каждый ресурс один раз: entry + его статические импорты/CSS;
для маршрута добавляет динамический экран и родительский AccountLayout.
Gzip level 9 и Brotli quality 11 считаются отдельно для каждого файла и суммируются.
Это размеры возможной передачи артефактов, не измерение скорости соединения,
времени рендера или утверждение, что dev-сервер применяет сжатие.

Каждая обычная сборка проверяет бюджеты своей конфигурации; `frontend:verify`
проверяет максимальную конфигурацию в существующем CI job.

## Результат

Все размеры в байтах. «Маршрут» включает начальные зависимости и layout;
размеры разных маршрутов не нужно складывать.

| Набор | JS raw | JS gzip | JS Brotli | CSS raw | CSS gzip | CSS Brotli |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Storefront: начальный | 267812 | 88206 | 78481 | 19851 | 4914 | 4245 |
| Storefront: вход | 282434 | 93042 | 82645 | 21287 | 5433 | 4641 |
| Storefront: профиль, наибольший маршрут | 341511 | 115372 | 101680 | 29771 | 7527 | 6421 |
| Storefront: адреса | 301321 | 101800 | 90044 | 28335 | 7008 | 6025 |
| Seller: вход | 283402 | 94036 | 83533 | 22131 | 5731 | 4905 |

| Staff: приглашение, наибольший маршрут | 216616 | 69857 | 61238 | 19851 | 4914 | 4245 |

Storefront имеет 14 динамических точек входа, staff — 3. Staff отсутствует в manifest
storefront. Начальный граф включает Vue, protobuf/Connect и координатор сессии;
дальнейшее уменьшение этих библиотек не входит в перенос границ MM-87.
Исходный аудит фиксировал единый JS 402273 байта с 15 экранами; это другой срез
кода. Процент ускорения на основании этих двух чисел не заявляется.

## Бюджеты и регрессии

Лимиты закреплены в `frontend/bundle-budgets.json`. JS округлён вверх шагом 32 KiB,
CSS — 4 KiB, с небольшим запасом для обычных изменений; превышение требует
объяснения причины и нового измерения в PR. Порог покрытия и платный сервис не нужны.

| Приложение | Начальный JS | Маршрут JS | Начальный CSS | Маршрут CSS |
| --- | ---: | ---: | ---: | ---: |
| Storefront | 294912 | 360448 | 24576 | 36864 |
| Staff | 229376 | 229376 | 24576 | 24576 |

Production browser-тест проверяет сетевые запросы покупательского входа, появление
seller-чанков только после перехода, стили при прямом входе в seller, отсутствие
staff в графе и старую прямую ссылку с `#fragment` при недоступном чанке.
Восстановление происходит только по явному действию: URL сохраняется, документ
перезагружается один раз, мутации не повторяются. HTML — `no-store`, хешированные
assets — `immutable`; неизвестный ресурс не возвращает SPA вместо JavaScript.

Отдельный реальный staff E2E задерживает lazy login-чанк во второй вкладке:
смена сессии скрывает персональные данные до завершения загрузки. Контрактные
браузерные тесты удерживают ответ StartSso и проверяют отмену устаревшего перехода
при уходе со страницы и межвкладочной invalidation.
